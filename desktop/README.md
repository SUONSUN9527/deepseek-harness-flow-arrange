# DeepSeek Harness Desktop

English | [中文](README.zh.md)

A local desktop shell modeled after the Codex desktop app: double-click to start, choose a workspace, and the app launches `dsh web` locally with the DeepSeek session UI embedded in the window. All code is isolated in this directory and is not part of the pnpm workspace build.

## Usage

Recommended: double-click the **DeepSeek Harness** desktop icon (no console window). If the icon is missing, double-click `创建桌面快捷方式.bat` in this directory to create it.

You can also double-click **`启动 DeepSeek Harness.bat`** directly.

1. Double-click **`启动 DeepSeek Harness.bat`**.
   - The first run automatically executes `npm install` to install Electron (the npmmirror registry is preconfigured), then opens the window.
   - Node.js must be installed, and the repository must have completed `pnpm run build` so that `apps/cli/lib/bin.js` and `apps/web/dist` exist.
2. Choose a workspace on the launch page (or click a recent workspace on the left) and click **Start session**. DeepSeek native mode is selected by default; Agent orchestration remains available as an explicit choice.
3. The app selects an available port, launches `dsh web --no-open --port <port>` with the workspace as cwd, and opens the session UI in the window when ready.
4. The application menu provides `‹ 返回` to stop the service and return to the launch page and `浏览器打开` to open the same service in the system browser. Shortcuts are `Ctrl+Shift+H` for the launch page and `Ctrl+Shift+I` for developer tools.

## Advanced options

| Option | Description |
|---|---|
| Port | Leave blank to allocate an available port automatically |
| Extra arguments | Append arguments to `dsh web`, such as `--patch ./extra.yml` |
| dsh entry override | Use another `bin.js`; defaults to `apps/cli/lib/bin.js` in the repository and falls back to `dsh` on PATH |
| Node path override | Defaults to `node` on PATH and falls back to Electron's bundled Node runtime |

## Agent orchestration mode

Agent orchestration keeps Claude as the orchestrator and Codex as the worker. The orchestrator can use Auth login or `ANTHROPIC_API_KEY`; the worker uses Codex native Auth or API-key configuration. Their authentication state is independent. The worker model is managed by the native Codex configuration, while the Web Models page only selects the orchestrator model.

## Memory and persistence

| Content | Location | Description |
|---|---|---|
| Session history and dsh settings | `~/.dsh/` (`sessions`, `settings.yaml`, `storages`) | Persisted by dsh across launches |
| Recent workspaces and desktop settings | `dsh-desktop.json` under Electron `userData` | Maintained by the desktop shell |
| Embedded-page browser state (such as localStorage) | Electron `userData` | Isolated by origin (including port); DeepSeek defaults to fixed port **26100**, Agent orchestration defaults to **18080**, and a random port is used only when the default is occupied |

## Icon and desktop shortcut

- `app.ico` is generated by `scripts/make-icon.js` (Electron renders `scripts/icon.html` off-screen and exports 16–256 px sizes). After changing the style, run `node_modules\\.bin\\electron scripts\\make-icon.js` again.
- `创建桌面快捷方式.bat` creates a **DeepSeek Harness** shortcut on the current user's desktop. It points directly to `electron.exe` and starts without a console window (run the startup bat once first to install dependencies).

## Directory layout

```
desktop/
├── 启动 DeepSeek Harness.bat   # 双击入口（首次自动装依赖）
├── package.json
├── main.js                     # 主进程：服务生命周期、窗口、WebContentsView 内嵌、IPC
├── runtime-config.js           # 模式到 Harness home/profile/端口的纯配置解析
├── preload.js                  # contextBridge API
└── renderer/                   # 启动器前端 UI（无框架，纯 HTML/CSS/JS）
    ├── index.html
    ├── app.css
    └── app.js
```
